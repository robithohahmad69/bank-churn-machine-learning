01

Preprocessing

Arviansyah · preprocessing.py
Apa?

Pemeriksaan kualitas data sebelum dipakai: missing value, duplikasi, dan outlier (metode IQR pada kolom numerik kontinu).

Untuk apa?

Agar model belajar dari data yang bersih dan konsisten. Nilai kosong atau baris ganda bisa membuat pola yang dipelajari menjadi bias atau salah.

Kenapa begitu?

Hasil aktual: missing 0, duplikasi 0 — tidak perlu handling. Outlier (usia lansia, credit score rendah) tidak dihapus karena valid secara domain bisnis, dan Decision Tree tidak sensitif terhadap outlier maupun skala fitur. Menghapusnya justru membuang informasi.

02

Split Data
80% : 20%

Arviansyah · transformation.py
Apa?

Data dibagi dua: 80% training untuk melatih model dan 20% testing untuk mengujinya. Pembagian bersifat stratified (proporsi churn tetap sama di kedua bagian) dengan random_state=42 agar dapat direproduksi.

Untuk apa?

Untuk mengukur kemampuan model pada data yang belum pernah dilihat. Menilai model dengan data latihnya sendiri seperti menilai ujian dengan soal yang sudah dihafal — hasilnya menipu.

Kenapa di sini?

Split dilakukan sebelum transformation: encoder hanya boleh di-fit pada data training. Jika encoder melihat data testing lebih dulu, informasi dari data uji "bocor" ke proses pelatihan (data leakage) dan skor evaluasi menjadi terlalu optimis.

03

Transformation
One-Hot Encoding

Arviansyah · transformation.py
Apa?

Kolom kategorikal (country, gender) diubah menjadi kolom biner 0/1 lewat One-Hot Encoding dengan drop="first". Fitur numerik diteruskan tanpa diubah (passthrough).

Untuk apa?

Model matematika tidak bisa menghitung teks seperti "France" atau "Male". Encoding menerjemahkannya menjadi angka tanpa menciptakan urutan palsu (misalnya France=1, Spain=2 seolah Spain "lebih besar").

Kenapa begitu?

drop="first" menghindari dummy variable trap (kolom redundan yang saling menjelaskan). Encoder di-fit hanya pada training, lalu testing hanya di-transform — mencegah data leakage. Numerik tidak di-scale karena Decision Tree membagi data berdasarkan ambang batas, bukan jarak antar-titik.

04

Resampling
SMOTE & RUS

Marsha · resampling.py
Apa?

Dua strategi menyeimbangkan kelas pada data training saja: SMOTE (oversampling) membuat sintesis sampel baru kelas minoritas; RUS (undersampling) menghapus sampel kelas mayoritas secara acak.

Untuk apa?

Data asli sangat timpang (± 80% : 20%). Model yang jujur pada data timpang akan pintar memprediksi kelas mayoritas dan "malas" menangkap churn — persis kelas yang justru paling penting dideteksi.

Kenapa hanya training?

Data testing harus tetap mewakili dunia nyata yang timpang. Meresample data uji sama dengan mengubah soal ujian agar sesuai dengan jawaban — metrik evaluasi menjadi tidak sah. Inilah aturan tegas panduan UTS.

05

Klasifikasi
Decision Tree

Marsha · model.py
Apa?

Algoritma pohon keputusan: data dipecah berulang kali berdasarkan pertanyaan ambang batas (misalnya "usia > 45?") hingga sampai di daun keputusan. Dua pohon dilatih — satu pada data hasil SMOTE, satu pada data hasil RUS (random_state=42).

Untuk apa?

Menangkap pola non-linear antara fitur dan churn tanpa perlu asumsi bentuk hubungan, sekaligus mudah dijelaskan ke orang bisnis: jalur pohon bisa dibaca sebagai aturan "jika … maka …".

Kenapa Decision Tree?

Tidak sensitif terhadap outlier (yang kita pertahankan di tahap preprocessing), tidak butuh normalisasi (sehingga transformation cukup dengan encoding), serta mampu menangani campuran fitur numerik, biner, dan hasil encoding secara langsung.
